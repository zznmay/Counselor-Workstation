## 0. 一句话需求

在**不动桌面端、不新增后端能力、不改动品牌色令牌**的前提下，把「杭科院辅导员工作台」的**移动端登录页（≤768px）**按参考图的**版式语言与极简气质**重做，产出一张**高保真效果图**；参考图的「社交登录 / 忘记密码 / 纯黑主按钮 / 风景头图」四处**必须本地化改造**，以符合本项目「自建账号 + 内网校园系统 + 未来界面蓝」的真实约束。

**本页承载两条真实路径（同一页两态）**：
1. **登录态**：用户名 + 密码 → `POST /api/auth/login`；
2. **首次强制改密态**：登录成功但 `mustChangePassword=true` → 同页切换为「新密码 + 确认新密码」→ `POST /api/auth/change-password`。

## 1. 设计需求五要素

### 维度 1 · 场景（Surface）

| 项 | 结论 | 理由 |
|----|------|------|
| 产出形态 | **移动端 Web / H5 单屏登录页**（≤768px 视口），非原生 App、非小程序 | 沿用现有 Vite + React SPA 与路由，桌面端登录页保持不变 |
| 页面性质 | **单屏、竖向、无滚动优先**（360px 窄屏允许极轻滚动，见 T8）；**同页两态**（登录 / 首次改密） | 登录页是「入口单屏」，不宜长滚动；改密态由代码在同一路由内切换 |
| 使用情境 | 辅导员在手机浏览器 / 内网 H5 容器打开工作台，**首次或重新登录**；多发生在**走动中、单手、可能弱网** | 与 `01-需求摘要` 受众一致；登录页更强调「一步到位、不卡顿、看得懂」 |
| 特殊定位 | 登录页是**第一印象页 + 安全信任建立点** | 需承载「内网部署、数据不出校、账号由管理员开设」等合规章实信息，建立使用信任 |

### 维度 2 · 受众（Audience）

| 项 | 结论 | 理由 |
|----|------|------|
| 核心用户 | **高校辅导员**（主责 + 共管），少量管理员 | 与全站一致（`01-需求摘要` §1 维度 2） |
| 技术素养 | **中低**：熟悉微信/办公类 App，不懂设计术语 | 登录交互必须遵循**通用范式**（图标含义唯一、无自创手势、无隐藏入口） |
| 使用心理 | **任务驱动、时间紧张**：只想「快点进去办事」；对红色报错敏感 | 登录路径要**最短**；错误提示要**就近、说人话** |
| 语言 | **中文优先**；英文仅可作极小的风格点缀，不得作主信息 | 受众英文素养有限，参考图为英文标题需本地化 |
| 数据敏感度 | **高**：内网系统、仅授权教师可用 | 页面文案需体现合规与边界（授权范围、账号来源） |

### 维度 3 · 调性（Tone）

- **延续「未来界面蓝」单一视觉语言**：单色系 + 水彩晕染 + 分层卡片；**不引入新色相**。
- 视觉学派：**Modern Minimal（现代极简）为主 + 参考图带来的 Editorial 编辑感**——登录页无数据密度压力，是本项目**唯一适合放大留白、上「非对称曲线」与品牌头图**的页面。
- 手机端调性：**大量留白、层级靠字号/字重/间距**（而非色块），**黑白灰为主 + 品牌蓝提供氛围与行动色**。
- **不做**：Brutalist（与校园政务气质不符）、Soft Warm 暖色系（破坏蓝系品牌一致性）、3D 重阴影、装饰花纹。
- 用户本次诉求＝**借鉴参考图的「版式语言」**，而非替换品牌色；故「风格采纳」与「色彩沿用品牌」二者并行（详见 §3、§4）。

### 维度 4 · 品牌上下文（Brand Context）

| 项 | 结论 | 理由 |
|----|------|------|
| 品牌资产 | **已有且必须延续**，无需重新选型 | 已有完整 CSS 令牌 + AntD `ConfigProvider` 主题 |
| 锁定令牌（不得改动） | `--app-primary:#5F86FF`、`--app-primary-strong:#4A6FE3`、`--app-primary-soft:#A9C2FF`、`--app-ink:#2F3E66`、`--app-ink-secondary:#5A6B8C`、`--app-border:#E7EEFB` | 六枚品牌令牌只读（`02-设计令牌` §0） |
| 移动端可复用令牌 | 主按钮渐变 `--m-grad-primary:linear-gradient(135deg,#4568D8,#3A5BC8)`；深蓝渐变 `--m-grad-hero:linear-gradient(135deg,#2F3E66,#3556B8)`；卡片阴影 `--m-shadow-card`；焦点环 `--m-ring`；头像/徽标渐变白字全段 ≥4.5:1 | 直接复用，避免登录页自造一套 |
| 品牌标识 | 复用「**杭**」字**渐变徽标**（`.logo-badge` / `.tb-logo`，全站统一语言）+ 品牌名「杭科院 · 辅导员工作台」 | 登录页现有实现即用「杭」字徽标，保持一致（全称：杭州科技职业技术学院） |
| 图片素材 | **无品牌照片/图片素材**（`public/` 仅 `templates`、`tools`；`src/assets/` 为空） | 参考图的风景头图**无对应素材**，头图须由 CSS 渐变生成（见 §4 冲突 4） |
| 主题模式 | 仅亮色（`App.tsx` 未接 `darkAlgorithm`） | 本期只出亮色稿（继承 `01-需求摘要` `H1`） |

### 维度 5 · 规模（Scale）

| 项 | 结论 | 理由 |
|----|------|------|
| 页面数 | **1 个页面**（移动端登录页），含**2 个表单态**（登录 / 首次改密） | 单屏改版 |
| UI 状态数 | **6 个必需状态 + 5 个建议状态**（详见 §5） | 状态完整性直接决定效果图可用度 |
| 响应式 | 仅移动端；基准 375–430px，**窄屏兜底 360px**；桌面端登录页**零改动** | 硬约束 |
| 交互复杂度 | 低（表单 + 显隐切换 + 状态切换），**无复杂动画**；动效统一 Subtle（≤350ms） | 与全站一致 |
| 交付物 | **一张高保真移动端效果图 / 原型**（含主要状态），供用户确认后再进入代码 | 「先出效果图」是本次明确诉求 |

## 2. 页面结构分层（自上而下）

> 采用参考图的「**上部头图 + 下部白卡**」双段结构，但头图内容与色彩全部本地化。白卡**左右留边（约 16–20px）浮于背景之上**，使非对称圆角可被看见（参考图的关键签名）。卡内所有层级**只靠字号 / 字重 / 间距**建立，不靠加色块。

```
┌─────────────────────────────┐  ← 状态栏安全区 env(safe-area-inset-top)
│  A  品牌头图区（Hero）        │  品牌蓝水彩渐变 + 「杭」徽标 + 品牌名 + 合规章实
│                             │  （约占屏高 30–38%，为白卡非对称圆角让位）
│   ╭─────────────────────╮   │  ← 白色卡片，左上超大圆角 / 右上小圆角
│   │ B1 标题区            │   │
│   │ B2 输入区            │   │
│   │ B3 辅助提示行        │   │
│   │ B4 主按钮（胶囊）    │   │
│   │ B5 协议勾选区        │   │
│   ╰─────────────────────╯   │
│                             │
│  C  底部信息徽标区（三枚）    │  静态信任徽标，等距排列
│                             │
└─────────────────────────────┘  ← env(safe-area-inset-bottom)
```

### 区块 A · 品牌头图区（Hero）—— 职责：品牌识别 + 氛围 + 合规信任

- **内容（信息优先级 高→低）**：
  1. 「杭」字渐变徽标（复用全站 Logo 语言）；
  2. 品牌名「杭科院 · 辅导员工作台」；
  3. 一行合规章实小字「内网本地化部署 · 仅限授权教师使用」（沿用现有登录页文案）。
- **视觉**：品牌蓝**水彩晕染渐变**（复用 `02-设计令牌` §15.1 四层晕染思路），无照片。
- **作用**：① 提供参考图中「照片头图」所承担的**氛围与色块**功能；② 承载品牌与合规章实；③ 为白卡的非对称大圆角提供「压边」背景。

### 区块 B · 白色卡片主体 —— 职责：承载全部登录行为

**非对称圆角**：左上**超大圆角**、右上**小圆角**（参考图的标志性曲线）。⚠️ 该数值（目视 60–80px）**超出既有圆角令牌**（最大 `--r-sheet:22px`），需**新增一枚「登录页专属圆角令牌」**（建议 44–56px，见 T9），并在令牌文档登记；**不属于品牌色锁范围，允许新增**。

| 子块 | 职责 | 信息优先级 / 内容 |
|------|------|-------------------|
| **B1 标题区** | 情感化问候 + 任务引导 | 主标题（大号粗体）→ 副标题（浅灰小字）。**无分割线、无装饰线**（参考图特征）。默认中文「欢迎回来」/「请使用管理员开设的账号登录」（见 T7） |
| **B2 输入区** | 采集账号凭证 | ① 用户名（前置人形图标 `UserOutlined`）；② 密码（前置锁图标 `LockOutlined` + **右侧眼睛图标**显隐切换，AntD `Input.Password` 自带）。**浅灰填充、无边框**的圆角输入框，占位「用户名」「密码」，字号 **16px**、高 **44px** |
| **B3 辅助提示行** | 替代参考图「忘记密码?」，承载真实提示 | 原「忘记密码?」位置 → 替换为**真话微文案**（默认「忘记密码请联系管理员」，右对齐、灰色、**非链接样式**，避免假按钮），见 §4 冲突 2 |
| **B4 主按钮** | 主行动 | 全宽**胶囊形**「登 录」，高 44–48px，**品牌蓝渐变**（复用 `--m-grad-primary`），非纯黑，见 §4 冲突 3 |
| **B5 协议勾选区** | 合规确认 | 方形勾选框（`--cb-size:18px`，热区撑到 44px）+ 小字「我已阅读并同意平台的《用户隐私协议行为准则》」（约 11–12px 灰字）。**本项目原无此项，为本次新增**，见 T5/T6 |

> **首次改密态**（同页切换，非新区块）：B1 标题改「设置新密码」；B2 改为「新密码 + 确认新密码」（均带锁图标 + 眼睛）；B3 改为账号说明「当前账号：xxx，首次登录请设置不少于 8 位（含字母和数字）的新密码」；B4 按钮改「设置并进入系统」；**B5 协议区在改密态下可省略**（协议已在登录态确认）。

### 区块 C · 底部信息徽标区 —— 职责：替代社交登录行，承载真实信任信息

- 三枚**等距排列的圆角方形徽标**（视觉沿用参考图的 `≈48×48px、圆角≈14px、浅灰底` 节奏），但**承载真实信息、为静态、不可点击**（无按压态、无按钮态，避免「假 affordance」）。
- 默认文案（三选三）：**「内网部署」「数据不出校」「管理员开设账号」**（各配一枚线性图标）。
- 理由与备选见 §4 冲突 1。

### 区块 D · 安全区留白

- 底部 `padding-bottom: calc(16px + env(safe-area-inset-bottom))`，保证内容不被小黑条遮挡。

## 4. 三个（含头图共四个）「不可照搬」冲突 · 处理建议

### 冲突 1 · 底部三枚社交登录图标（本项目无社交登录）

| 备选 | 评价 |
|------|------|
| **① 改为三枚真实信息徽标**（内网部署 / 数据不出校 / 管理员开设账号） | ✅ **推荐** |
| ② 改为「联系管理员 / 使用说明 / 安全提示」入口 | ❌ 其中「使用说明 / 安全提示」无对应页面，仍是假入口；「联系管理员」与辅助提示行重复 |
| ③ 整行删除，留白让给品牌区 | ⚠️ 可用作极简兜底，但会**丢失参考图「三等分方块」的版式记忆点**，卡片底部偏空 |

**推荐 ①**，理由：
1. **保住版式签名**——三枚等距圆角方块是参考图下半部的视觉节奏，删除即削弱「神似」；
2. **装饰 → 真实信任信号**——本项目受众对「内网 / 合规 / 账号来源」高度敏感，这三条恰是真实且有用的事实；
3. **无假 affordance**——做成**静态、无按压、无按钮态**，不误导用户去点（Anti-Slop）。
- 若用户更偏好极简，则退化为备选 ③，并在交付说明标注。

### 冲突 2 · 「忘记密码?」（本项目无自助找回）

| 备选 | 评价 |
|------|------|
| **① 替换为真实提示文案**（默认「忘记密码请联系管理员」） | ✅ **推荐** |
| ② 改为「联系管理员」说明行 | ⚠️ 与 ① 基本等价，可视为 ① 的实现细节 |

**推荐 ①**：在**原「忘记密码?」的位置与节奏**上，替换为**真话微文案**（右对齐、灰色、`--m-text-2`、**不加下划线/链接色**，明确「这不是一个可点链接」）。
- **去重**：现有登录页底部已有一句「账号由系统管理员统一开设，忘记密码请联系管理员」；本次将其**合并到该辅助行**或保留于卡片底部，**避免同页两处重复**（具体位置见 T4）。
- 若将来提供管理员联系方式，可将此文案升级为**可点的「联系管理员」**并跳转底部抽屉展示联系方式；当前无该数据，故先做**非交互文本**。

### 冲突 3 · 主按钮纯黑 vs 品牌蓝

| 备选 | 评价 |
|------|------|
| **① 品牌蓝渐变**（`linear-gradient(135deg,#4568D8,#3A5BC8)`，复用 `--m-grad-primary`） | ✅ **推荐** |
| ② 深色高级感，但用**深界面蓝 `#2F3E66`**（`--app-ink`，属品牌色系） | ⚠️ 备选，仅在用户明确想要参考图「纯深色克制感」时采用 |

**推荐 ①**，理由：
1. **设计系统一致性**——全站（工作台/学生/预警…）主按钮均为该品牌蓝渐变；仅登录页用黑色/深色会读作「另一个系统」，破坏一致性；
2. **用户明确要求**「配色以未来界面蓝为主」；
3. **可访问性达标**——该渐变两端白字对比度 `4.97:1` / `5.98:1` 均 PASS（`02-设计令牌` §15.4）；
4. 参考图的「克制高级感」可由**大留白 + 非对称圆角 + 深浅层级**来承担，不必靠黑色按钮。
- ⚠️ 若用户坚持参考图的纯深色质感，则退化为备选 ②，**用 `#2F3E66` 而非纯黑**，以留在品牌色系内；此决定登记为 T1。

### 冲突 4 · 顶部照片头图（本项目无合适素材）

| 备选 | 评价 |
|------|------|
| **① 品牌蓝水彩晕染渐变 + 院徽/校名文字构成头图** | ✅ **推荐** |
| ② AI 生成的蓝调校园意象图 | ⚠️ 备选，可选增强 |

**推荐 ①**，理由：
1. **零素材依赖**——`public/` 与 `src/assets/` 均无图片，CSS 渐变可即刻交付；
2. **品牌一致**——直接落在「未来界面蓝」晕染体系内（复用 `02-设计令牌` §15.1 四层晕染）；
3. **规避风险**——照片/生成图存在版权、审美、以及「**虚构校园形象与真实杭科院不符**」的误导风险；内网校园系统宜稳重克制；
4. **功能等价**——参考图的照片主要提供「色块 + 氛围 + 与白卡形成对比」，水彩渐变完全能承担该结构角色。
- ⚠️ 若采用备选 ②（AI 图），须确保：与品牌蓝调统一、**不出现虚构校徽/校名**、与白卡交叠处足够深以让非对称圆角可辨；并作为**可选皮肤**，默认仍用 ①。

## 6. 硬性约束（沿用令牌，供设计系统与原型阶段强制）

**触控**
- 交互元素热区 **≥44×44px**；相邻可点元素间距 **≥8px**；输入控件 `min-height:44px`。

**字号与可访问性**
- 输入 / 文本域字号 **≥16px**（iOS 防缩放红线）；正文对比度 **≥4.5:1**；占位符用 `--m-placeholder`（on `#F7F9FF` 4.65:1 / on 白 4.90:1 ✅）；错误文案 `--danger-fg` on 白 5.84:1 ✅；**状态不得仅用颜色**（勾选/错误须带文字或图标）。

**布局**
- 视口高度 `100dvh`（不用 `100vh`）；`viewport-fit=cover` + `env(safe-area-inset-*)`（顶部与底部）；**禁止横向滚动**。

**动效**
- Subtle 级（≤350ms；本项目档位 80/150/200/240ms），仅 `transform` / `opacity`，按压 `scale(.97)`；**必须尊重 `prefers-reduced-motion`**。

**品牌与范围**
- 品牌六枚令牌**不得改动**；**不引入新色相**；主按钮白字对 `--app-primary-action` = 4.97:1。
- 移动端卡片阴影**仅一级**（`--m-shadow-card`）。
- **桌面端登录页保持不变**，本次仅做移动端。

**⚠️ 允许的「新增令牌」（非改值）**
- 登录页**专属圆角**（非对称大圆角，建议 44–56px）属**新增**，需在 `02-设计令牌` 登记为「登录页专属扩展」；不触碰品牌色令牌。
