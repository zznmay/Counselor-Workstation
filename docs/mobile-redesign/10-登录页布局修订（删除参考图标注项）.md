## 5. 响应式

根字号规则由宽度等比改为**宽高双向兜底**：

```css
html{ font-size:min(calc(100vw / 43.2), calc(100dvh / 76.8), 10px); }
```

- 宽视口（≥9:16，如 390×844）→ 由宽度项决定，卡片按参考图比例呈现并上下留白；
- 矮视口（<9:16，如 375×600）→ 由高度项接管再缩一档，**整屏完整呈现、不出现滚动**。

卡片居中改用 `.card{margin:auto}` 而不是 `align-items:center`：视口过矮时 auto 外边距归零、卡片退回顶部对齐并可滚动，避免「flex 居中导致顶部被裁且无法触达」的经典陷阱。

实测（`tools/render-devices.cjs`）：

| 设备 | 根字号 | 卡片 (x, y, w, h) | 页面滚动高 | 结论 |
|---|---|---|---|---|
| 320×568 | 7.396px | 31.7, 29.6, 256.7, 508.8 | 568 | 无滚动 |
| 375×667 | 8.681px | 36.9, 34.9, 301.2, 597.2 | 667 | 无滚动 |
| 375×600（矮屏压测） | 7.813px | 52.0, 31.3, 271.1, 537.5 | 600 | 无滚动、顶部未裁 |
| 390×844 | 9.028px | 38.4, 111.5, 313.3, 621.0 | 844 | 居中留白 |
| 430×932 | 9.954px | 42.3, 123.6, 345.4, 684.8 | 932 | 居中留白 |
| 432×768（参考画布） | 10px | 42.5, 40.0, 347, 688 | 768 | 基准 |

## 6. 可随时回退 / 微调的点

1. **版权行**：若要恢复「技术支持 / © 年份」两行，在 `.panel` 末尾加
   `<p class="foot">…</p>` + `.foot{margin-top:auto;padding-top:2rem;text-align:center;font-size:.9rem;line-height:1.5rem;color:#B0B1B5}` 即可，不影响其余间距。
2. **卡片是否居中**：本版居中（40/40）。若希望保持参考图「贴顶」观感，把 `.card{margin:auto}` 改为 `.card{margin:0 auto}`，卡片将回到 y 20 起始、下方留 60。
3. **社交登录恢复**：图标素材仍在 `prototype/assets/icon-dingtalk|wechat|wecom.png`，`build-login.py` 取消注释即可重新内嵌；但**需先补后端能力**，否则仍是「点了弹真话」。
4. **品牌文案仍是参考图占位**（知行 / 以知润心 以行育人 / 知行合一 · 育见未来 / 知行辅导员工作台）—— 未在本次标注范围内，保持原样。落地 `src/` 前建议替换为杭科院实际文案。
5. **字体**：仍为 `Noto Sans SC / PingFang SC / Hiragino Sans GB` + 大标题 `-webkit-text-stroke:.4px`；有品牌 Heavy 字体可进一步压低字形差异。
