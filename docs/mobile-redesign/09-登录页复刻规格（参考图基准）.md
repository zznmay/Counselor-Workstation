## 4. 关键结构（易错点）

> **头图必须延伸到白面板背后。**
> 参考图中白面板右上 80px 大圆角的缺口里露出的**是照片，不是白底**；若把头图高度设为 261.5 并把卡片底设成白色，缺口会变白，风格立刻不对。
>
> 实现：`.hero{height:350px}` + `.panel{position:relative;z-index:1;margin-top:-88.5px}`。
> 头图 350 高覆盖了 281.5 + 80 = 361.5 的最大圆角需求，故留 350 足够（实测面板顶沿曲线与参考图完全重合）。

## 5. 落地到 `src/` 前必须处理的 3 件事

1. **品牌文案是参考图的占位**：`知行` / `知行辅导员工作台` / `以知润心 以行育人` / `知行合一 · 育见未来` / `技术支持：知行科技有限公司` / `© 2024 知行平台 版权所有` —— 需替换为杭科院实际文案（校名、校训、技术支持单位、年份）。
2. **三项能力当前系统并不存在**，复刻稿按参考图**如实呈现**但点击给出真话提示，接入前不要伪装成功：
   - `验证码登录` —— 系统无短信登录
   - `钉钉登录 / 微信登录 / 企业微信登录` —— 无三方登录
   - `忘记密码?` —— 无自助找回，实际流程是联系管理员重置
   接入方式建议：确认不做 → 直接删除该元素（版面会略变，需重新对齐）；确认要做 → 补后端后再打开。
3. **字体**：参考图所用中文黑体（大标题极重）本机无对应字重，现落定 `"Noto Sans SC","PingFang SC","Hiragino Sans GB"` + 大标题叠 `-webkit-text-stroke:.4px`。若接入方有品牌字体（如阿里巴巴普惠体 Heavy），换掉后差异可进一步下降。

## 6. 交互（已实现，非静态图）

| 交互 | 行为 |
|---|---|
| 密码眼睛 | 切换 `type=password/text`，同步 `aria-pressed` 与 `aria-label` |
| 协议勾选 | 原生 checkbox，`appearance:none` 自绘（11.5px + 圆角 3 + 勾号） |
| 未接入项点击 | 弹出如实说明，**不伪造登录成功** |
| 焦点态 | 输入框 `:focus-within` 边框转 `#B9C6DE`，无外发光（贴合参考图的克制风格） |
| 动效 | 仅按压 `scale(.985)` 与 150ms 过渡；`prefers-reduced-motion` 下全部关闭 |
