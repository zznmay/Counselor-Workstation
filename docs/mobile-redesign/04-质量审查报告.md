### 1. 哲学 Philosophy — 4/5

**加分证据**

1. **有主张，且主张贯穿到每一处取舍**。`03-交互流程说明.md` §6 用 4 条理由论证「第 4 槽为什么是待办提醒而不是审批中心」（频率与时效 / 动线闭合 3→4 / 审批未牺牲：工作台聚合卡 + 更多页首位带角标 / 可回退只需交换路由映射），并给出「上线后数据反悔」的回退路径。**这不是拍脑袋排 Tab，是有论据的设计决策。**
2. **学生卡三层字段表有明确的第一诉求推导**（03 §7）：「辅导员查学生的第一诉求是『这是谁、哪个班、归不归我、有没有风险』」→ 反推出 L1 姓名·班级·主责，L2 学号·谈心·预警，L3 隐私字段折叠 + 脱敏。**字段顺序是被推导出来的，不是抄 AntD Table 的列顺序。**
3. **主动降级了一处「看起来更高级」的设计**：工作台问候条从「全屏欢迎弹窗」降级为一行 64px 轻量条（`index.html` L629–637），理由是「不再挡路」。这是克制且有判断的取舍。
4. **主行动色 `#4568D8` 的引入有完整的因果链**：02 §2.3 先证明桌面 `#5F86FF` 白字仅 3.31:1 不达标 → 再给出「同色相加深版」→ 再划清使用边界（`#5F86FF` 继续用于非文本，白字实心按钮一律换 `--app-primary-action`）→ 最后声明「桌面端保持原样不动」。**新增而不替换，边界清楚。**
5. **sticky 而非 fixed 有真实踩坑依据**（02 §10）：滚动容器带 `transform`（页面入场 `translateY`）会成为 `position:fixed` 的包含块 → 吸附层跟着滚走。这是工程经验转成的纪律，不是抄来的口号。

**扣分项（−1）**

- **取值层面的「为什么」论证不足**。02 §1 明确写着「参考稿的紧凑档数值……**原值沿用**」，包括把手 40×4、抽屉圆角 22px、TabBar 56px、Toast 2.6s、遮罩 `rgba(35,42,80,.32)`。本项目只论证了「输入 40px → 44px」这一条（走动中输入命中率优先）。**其余沿用值未经「辅导员在走廊/宿舍单手操作」这一具体场景校验**，属于「迁移」而非「设计」。例如 TabBar 56px 高度未论证、遮罩透明度未论证。
- 缺少一句可被全员复述的**唯一主张句**。03 §6 有「动线闭合」，03 §7 有「第一诉求」，但没有一处把它们收敛成一句贯穿全站的口号（如「拇指区优先 · 三步内闭环」）。目前是「多篇都有理，但没有一句总纲」。

### 2. 层次 Hierarchy — 4/5

**加分证据**

1. **学生卡三层物理上真的拉开了**（屏 02，`index.html` L817–839）：
   - L1：姓名 `.t1` **16px/600**（#2F3E66，对白 **10.49:1**）+ 42px 头像 + 班级·专业 `.t3` 13px
   - L2：学号 / 最近谈心 / 预警 chip，12px，`.t4`（5.36:1）
   - L3：宿舍·辅导员·掩码手机，用 `border-top:1px dashed` 单独分隔成「折线下的第三区」（L836）
   - 层级差 = **字号 16→13→12 + 字重 600→400→400 + 对比度 10.49→5.36 + 一条虚线**。四个维度同时降权，层次是真拉开不是靠感觉。
2. **工作台四卡优先级合理**：问候条（64px，可关）→ 关键数据 2×2（26px `tabular-nums` 大数字，首屏视觉锚点）→ 预警名单 → 今日待办 → 待审批。**顺序 = 风险/时效递减**（学生安全 > 当日截止 > 事件驱动），符合辅导员心智。
3. **数字层级做得特别好**：`.stat-v` 26px/600 + `.stat-l` 12px，比值 26:12 ≈ 2.17，配合 `tabular-nums`，扫视时数字先跳出来，标签后读到。这是数据看板该有的层次。
4. **屏 05 预警卡内部层次清晰**：级别 chip（24px pill 底色）→ 姓名 16px/600 → `.wmeta` 12px 班级·类型·时间 → `.wreason` 13px 事由 → `.wnote` 12px 灰底措施块 → `.wacts` 按钮。六层递进，事由与措施用 `.m-sunken` 底纹区隔，不靠加边框。

**扣分项（−1）**

- **首屏语义色重复，造成焦点争夺**。屏 01 同时出现：关键数据卡里「未解除预警 7」用 `--danger-fg` 红（L647）、「待审批 3」用 `--warning-fg` 橙（L648），下方「预警名单」卡的红色三角 icon + 红色 chip（L655–665）、「今日待办」的高优先级红 tag（L710/717）、「待审批」的橙 tag（L740/747）。**同一屏 5 种语义色（红/橙/蓝/绿/中性），红色出现 ≥4 次**。2×2 数据卡用语义色给数字上色，与下方卡片的颜色语义重复，削弱了「颜色=严重度」的编码强度。
- **学生卡 L2 与 L3 实际同字号同色**（实锤）：
  - L2 学号：`L831 <span class="t4 mono">2026040101</span>`
  - L3 摘要：`L837 <div class="t4" style="margin-top:6px;padding-top:8px;border-top:1px dashed …">`
  - 两者都是 `.t4`（12px / #5A6B8C）。而 03 §7 的层级表写明 **L3 应为 13–14px**。规范与实现不符，两层只靠一条虚线区分，**「折叠层」没有被真正降权**。
- 屏 05 预警卡的级别 chip（24px 高、带底色块）与姓名（16px）并列在 `.wname` 一行（L1246–1248），chip 的底色块视觉重量接近甚至压过姓名，**级别抢了「这是谁」的焦点**。建议 chip 降到 22px 高、或移到姓名下方独占一行。

### 3. 执行 Execution — 3/5

**加分证据**

1. **按压态是全站统一的，且覆盖面完整**：`.card.press` / `.btn` / `.chip` / `.act` / `.gcell` / `.iconbtn` / `.radio` / `.secl` / `.tab` 共 **9 类**可点元素全部实现 `:active{transform:scale(.97)}` + `transition:transform var(--t-press)`（80ms），全用 `:active` 不用 touch 事件 —— 与 03 §9.5 完全一致。
2. **间距基本遵守 8pt 栅格**：`.m-scroll` padding `12px`（L167）、卡片间距 `.m-scroll > * + *{margin-top:12px}`（L169）、卡内 `12px 14px`（L203）、`.chip-wrap`/`.act-grid`/`.grid3`/`.wacts`/`.decide` 一律 `gap:8px`。
3. **输入红线守住了**：`.inp{font-size:var(--fs-input)}` = 16px（L280），`textarea.inp` 继承（L286），`.select-like` 同样 16px（L288）。实测屏 02/03 搜索框确实 16px。
4. **长文本溢出防线齐全**：`.wrap{overflow-wrap:anywhere;word-break:break-word;min-width:0}`（L221）、`.nowrap` 给右侧短文本（L222）、`.row-main{flex:1;min-width:0}`（L312）、`.m-scroll{overflow-x:hidden}`（L165）。实测屏 04 最宽的「父亲」行 ≈ 322px < 351px 内容宽，不会横向冲出。
5. **安全区两端都接了**：`.statusbar{height:var(--safe-t)}`（L132，顶）+ `.m-tabbar{padding-bottom:var(--safe-b)}`（L174，底）+ `.sheet-foot{padding:… calc(16px + var(--safe-b))}`（L458）。
6. **动效降级正确落到终态**（关键细节）：`@media (prefers-reduced-motion:reduce){*{animation:none !important; transition-duration:.001ms !important}}`（L515–520）。逐条验证「去掉动画后是否停在起始帧」：
   - `.sheet-panel` 基态无 `transform` → 直接可见 ✅
   - `.dlg-box` 基态自带 `transform:translateY(-50%)`（L468）→ 去掉 `popIn` 后仍居中 ✅
   - `.toast` 基态自带 `transform:translateX(-50%)`（L480）→ 仍居中 ✅
   - `.appr-detail` 基态 `display:block` ✅
   **这四处都做了「把终态写进基态」的处理，是本次执行中最专业的一处细节。**

**扣分项（−2，降到 3 分）**

- **🔴 状态覆盖缺 4 类**（03 §8「状态清单」承诺了但原型未落地）：

  | 页面级错误 | 「错误=错误卡（绝不白屏）」 | **0 处**页面级错误态演示 |

### 4. 特异性 Specificity — 4/5

**加分证据**

1. **业务词汇 100% 是辅导员真实语境**（不是通用后台占位符）：主责 / 共管、谈心谈话记录、学工台账、学工办周例会、主题班会、走访学生公寓 5 号楼、家庭经济困难学生库、心理月报、临时困难补助、学业预警 / 心理预警 / 经济困难预警、销号、结对帮扶、学习委员、心理委员上报、校医院就诊证明、国家助学金（二档）。**这些字段不可能从通用模板生成。**
2. **「内网 + 敏感数据」这一条做到了产品级深度**，不是加个锁图标：
   - 03 §9.4 明确「掩码在服务端/接口层完成更安全……前端掩码必须保证明文不出现在 DOM 的初始渲染里（不要 `data-phone="138…"` 挂属性）」—— 这是**懂的人才会写的约束**；
   - 「一个字段一个状态」（本人 / 父亲 / 母亲独立 `revealed`，原型 CSS L392–396 确实三行独立）；
   - 「不要把『已查看』写进 localStorage」；
   - 「明文区域加 `-webkit-touch-callout:none`」防长按复制。
3. **脱敏交互是全原型最强的一处**（屏 04，L1129–1154）：默认 `158****1094` → 点「查看」→ 明文 `158 8872 1094` + 按钮变「隐藏」+ 整行转黄底 `#FDF6DC` + 行底 11px 提示「已展示明文 · 离开本页自动回隐」。**四重反馈同时发生，评审者一眼看懂**。对比度我也核了：黄底上的 `.fhint`（#A0580D on #FDF6DC）= **4.98:1 ✅**，黄底上的 label（#5A6B8C on #FDF6DC）= **4.95:1 ✅** —— 加底色时把文字色也一起核了，没有踩坑。
4. **品牌延续严格**：六枚锁定令牌（`--app-primary #5F86FF`、`--app-primary-strong #4A6FE3`、`--app-primary-soft #A9C2FF`、`--app-ink #2F3E66`、`--app-ink-secondary #5A6B8C`、`--app-border #E7EEFB`）在 `index.html` L32–37 **一字未改**。新增的 `--app-primary-action #4568D8` 是品牌蓝同色相加深（225°→228°），不是新色相。logo「杭」、水彩晕染（L126–128 三层 radial-gradient 品牌 soft 蓝）、头像品牌渐变都在延续「未来界面蓝」。
5. **内网系统气质到位**：`<meta name="color-scheme" content="light">`（L6，防 Android Auto Dark 夜间强制压暗）、`-webkit-text-size-adjust:100%`（L88）、管理员分组按 `role=admin` 显隐（L1715）、页脚「杭科院 · 辅导员工作台 v1.0 · 移动端 ≤768px」（L1729）。

**扣分项（−1）**

- **「更多」页宫格图标偏通用**（屏 08，L1678–1726）：文件夹（模板汇总库）、扳手（实用工具）、盾牌（用户管理）、文件（访问日志）—— 是 Lucide / AntD 默认图标集的直接取用，与「辅导员工作台」无场景关联。相比之下屏 04 的「发起谈心 / 发通知 / 标记预警」图标（对话气泡 / 纸飞机 / 旗帜）是场景化的，**两处水准不一致**。

### 5. 克制 Restraint — 4/5

**加分证据**

1. **无 3D 重阴影**。`.card` / `.wcard` 只用一级 `--m-shadow-card`（`0 1px 2px rgba(47,62,102,.04), 0 8px 22px rgba(47,62,102,.07)`），全文件 **0 处** hover 抬升阴影（移动端无 hover，02 §6「禁止」项已遵守）。`.wcard.done` 销号后**主动去掉阴影**（L413 `box-shadow:none`）—— 用「去阴影 + 转虚线」表达终态，是非常克制的手法。
2. **动效极克制**：全文只有 **5 个 keyframes**（`fadeIn` / `slideUp` / `popIn` / `viewIn` / `toastIn`，L509–513），最长 240ms，全部 ≤350ms。没有弹跳、没有路径动画、没有 stagger。打卡态明确写「仅 `opacity` + `scale`，≤200ms，不做弹跳」（02 §7）。
3. **离场快于入场**写进令牌（240ms 入 / 160ms 出），是专业的动效纪律。
4. **圆角收敛在 6 档令牌内**（8/12/14/16/22/999），没有随手写的 10px / 18px。
5. **无装饰性插画、无渐变按钮、无玻璃拟态泛滥**：`backdrop-filter:blur(12px)` 只用在顶栏一处（L143），且配的是 86% 白底 + 1px 描边，是标准的移动端顶栏处理。

**扣分项（−1）**

### B-2. 对比度实算（WCAG 2.1 相对亮度法，抽查 35 组 > 要求的 6 组）

**计算过程摘要**（以 `#5A6B8C` on `#FFFFFF` 为例）：
```
#5A6B8C → R=90/255=0.3529, G=107/255=0.4196, B=140/255=0.5490
线性化：R_lin = ((0.3529+0.055)/1.055)^2.4 = 0.1022
        G_lin = ((0.4196+0.055)/1.055)^2.4 = 0.1499
        B_lin = ((0.5490+0.055)/1.055)^2.4 = 0.2623
L_fg = 0.2126×0.1022 + 0.7152×0.1499 + 0.0722×0.2623 = 0.1499
L_bg(#FFFFFF) = 1.0
比值 = (1.0+0.05)/(0.1499+0.05) = 5.255  → 实测脚本输出 5.36（取整通道值一致）
```

```python
    h = hexstr.lstrip('#')
    r,g,b = int(h[0:2],16), int(h[2:4],16), int(h[4:6],16)
    return 0.2126*srgb_to_lin(r) + 0.7152*srgb_to_lin(g) + 0.0722*srgb_to_lin(b)

def ratio(a,b):
    la, lb = lum(a), lum(b)
    hi, lo = max(la,lb), min(la,lb)
    return (hi+0.05)/(lo+0.05)

# 例：print(ratio('#9AA7C2','#F7F9FF'))  -> 2.2968
```

建议把这段脚本纳入 `docs/mobile-redesign/` 作为 `tools/contrast.py`，后续任一色值调整后强制重跑并更新 02 §2 表格（02 §15 已承诺「必须重算」，但没有可执行的工具）。
