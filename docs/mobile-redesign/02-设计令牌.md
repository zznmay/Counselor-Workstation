# 杭科院辅导员工作台 · 移动端设计令牌（Design Tokens）

> 产出人：原型构建师（筑原型）
> 阶段：Phase 2 / 设计系统
> 适用范围：**≤768px 视口的移动端呈现层**（桌面端 >768px 一律不受影响）
> 取值基准：
> ① 同域兄弟项目《学生考勤平台 · 移动端 UI 设计规范》（断点阶梯 / 触控铁律 / sticky 纪律 / 安全区 / 动效时长）

> 对比度：本文所有 ✅ 数值均由 WCAG 2.1 相对亮度公式实算（脚本核算，非估算）

## 0. 三条使用纪律（先看这里）

1. **品牌令牌只读**：`--app-primary` / `--app-primary-strong` / `--app-primary-soft` / `--app-ink` / `--app-ink-secondary` / `--app-border` 六个值**不得修改、不得替换**。移动端新增的是 `--m-*` 前缀的「移动呈现层令牌」。
2. **状态色只走语义 token**：业务代码里禁止出现裸 hex（`#C13A50` 这类只能出现在 `:root` 定义处一次）。
3. **移动端卡片阴影只有一级**（去掉桌面 `--app-card-shadow-hover` 的 hover 档）；浮层/吸附栏的投影不属于「卡片阴影」，单独定义两枚。

## 1. 断点阶梯（映射自参考稿 720/640/380/360；本项目窄屏兜底档下探至 ≤360）

| 本项目断点 | 对应参考稿 | 形态 | 关键变化 |
|---|---|---|---|
| `>768px` | `>920px` | **桌面（不动）** | 侧栏 224px + AntD Table + 分页器，本次**零改动** |
| `≤768px` | `≤720px` | **移动主设计面** | 挂载移动外壳：顶栏 + 单滚动容器 + 底部 TabBar；卡片化列表；弹窗→底部抽屉 |
| `≤576px` | `≤640px` | **紧凑（基准档）** | 输入 44px/16px；按钮 44px；底栏主按钮 48px；`.form-row` 转纵向；内容 padding 12px |
| `≤360px` | `≤380`（参考稿；本项目下探至 ≤360） | **窄屏兜底** | 快捷宫格图标 30px、字号 11px；按钮字号 13px；2×2 数据卡改单列×2 行 |

> 说明：参考稿的「紧凑档数值」（输入 40px/16px、按钮 44px、底栏 46px、复选框 18px、把手 40×4、抽屉圆角 22px）**原值沿用**；本项目把输入控件从 40px 提到 **44px**，是因为辅导员场景表单页（谈心记录、驳回意见）需要在走动中输入，命中率优先。

> **裁决留痕**：窄屏兜底档由 `≤380` 下探至 **`≤360`**（2026-10-14：375 为基准设计档，紧凑档须下探到 360 才是真兜底；`06` 登录页窄屏档同此）。

**⚠️ 实现现状（据实标注 · 2026-10-14 核对 `src/styles/mobile.css`）**

1. 当前 `src/styles/mobile.css` **仅实现 `@media (max-width:768px)` 一档**；`≤576px`（紧凑基准档）与 `≤360px`（窄屏兜底档）**均为「已定规格、尚未实现」**——代码中尚无对应媒体查询规则。
2. 因此现阶段在 **360–576px** 区间设备上，页面实际表现可能与 `≤576px` 档规格**存在偏差**（列为**实现待办**）。
3. `≤576px` / `≤360px` 两档规格**依然有效**，实现时应**以本表为准**。

| `--app-border` | `#E7EEFB` | 卡片描边、分割线 | 装饰 |

### 2.2 移动呈现层：表面与文字

```css
:root {
  /* 表面 */
  --m-bg:              #F4F7FF;  /* 页面底（与桌面 colorBgLayout 同值），水彩晕染叠加其上 */
  --m-surface:         #FFFFFF;  /* 卡片 / TabBar / 顶栏 */
  --m-surface-2:       #F7F9FF;  /* 次级面：输入框底、分组头、已完成折叠区 */
  --m-surface-sunken:  #EDF2FF;  /* 下沉面：分段控件底、骨架、chip 底 */

  /* 文字 */
  --m-text-1:          #2F3E66;  /* 一级  10.49:1 ✅ */
  --m-text-2:          #5A6B8C;  /* 二级   5.36:1 ✅ */
  --m-text-on-primary: #FFFFFF;  /* 主按钮字（配 --m-primary-action）4.97:1 ✅ */
  --m-text-disabled:   #9AA7C2;  /* 仅禁用态 2.42:1（WCAG 对禁用控件豁免） */
  --m-placeholder:     #64718D;  /* 占位符：on #F7F9FF 4.65:1 ✅ / on #FFFFFF 4.90:1 ✅ */

  /* 描边 */
  --m-border:          #E7EEFB;  /* 卡片/分割线 */
  --m-border-strong:   #8A94B5;  /* 控件边界：对白 3.01:1 ✅（WCAG 1.4.11 非文本对比 ≥3:1） */

  /* 焦点环 */
  --m-ring:            rgba(95,134,255,.34);
}
```

> ⚠️ **为什么没有三级文字**：参考稿的 `--text-3:#6B7694` 对白只有 `~4.3:1`，不满足本项目红线「正文 ≥4.5:1」。
> 因此本项目**只开放两级正文色**，第三级信息一律改用「二级色 + 更小字号 + 留白」表达，不靠降对比度。

> ⚠️ **占位符不是装饰色**：`--m-placeholder` 单独成令牌，不与 `--m-text-disabled` 复用。
> 原因：屏 02/03 的搜索框（`placeholder="搜索姓名 / 学号 / 班级"`）**没有可见 label**，placeholder 是唯一的字段说明、承载真实信息，
> 因此必须满足正文级 ≥4.5:1；而 `--m-text-disabled #9AA7C2`（2.30:1 on `#F7F9FF`）只能用于**禁用态**（WCAG 1.4.3 对禁用控件豁免），
> 值保持不变，只是**不再用于 placeholder**。二者分工：`--m-placeholder` = 未输入时的字段说明；`--m-text-disabled` = 不可用的控件文字。

### 2.3 主行动色（新增，不替换品牌色）

桌面端白字压 `#5F86FF` 只有 `3.31:1`（不达标），移动端必须给出一档「可承载白字」的主色：

```css
--app-primary-action:  #4568D8;   /* 白字 4.97:1 ✅ —— 实心主按钮 / 正文级链接 */
--app-primary-press:   #3F66DB;   /* 按压态，白字 5.08:1 ✅ */
--app-primary-tint:    #EDF2FF;   /* 选中态底纹；#3D5CD6 文字压其上 5.07:1 ✅ */
```

使用边界：**`#5F86FF` 继续用于图标、描边、渐变、进度条**（非文本）；只要出现「白字实心按钮 / 蓝字链接正文」就换 `--app-primary-action`。桌面端保持原样不动。

### 2.4 语义色（success / warning / danger / info）

每级四件套：`-fg`（文字/图标）、`-bg`（底纹）、`-bd`（描边）、`-solid`（实心底，白字）。

| 语义 | fg | bg | bd | solid | 核算 |
|---|---|---|---|---|---|
| **success** 成功/已解除 | `#25794A` | `#E3F6EC` | `#BFE3D0` | `#25794A` | fg on bg **`4.77:1` ✅**；fg on 白 **`5.37:1` ✅**；白 on solid **`5.37:1` ✅** |
| **warning** 警告/处理中 | `#A0580D` | `#FFF3E2` | `#F5DCB8` | `#A0580D` | fg on bg **`4.92:1` ✅**；fg on 白 **`5.39:1` ✅**；白 on solid **`5.39:1` ✅** |
| **danger** 危险/红色预警/逾期 | `#B8324A` | `#FDE9EE` | `#F7C9D3` | `#B8324A` | fg on bg **`5.03:1` ✅**；fg on 白 **`5.84:1` ✅**；白 on solid **`5.84:1` ✅** |
| **info** 信息/进行中 | `#3D5CD6` | `#E8EFFF` | `#CFDDFB` | `#3D5CD6` | fg on bg **`4.92:1` ✅**；fg on 白 **`5.68:1` ✅**；白 on solid **`5.68:1` ✅** |
| **neutral** 中性/草稿/已完成 | `#5A6B8C` | `#F0F4FB` | `#E0E8F7` | `#5A6B8C` | fg on bg **`4.86:1` ✅** |

> 与既有 AntD 语义色的关系：`colorSuccess:#5CA97F`（对白 `2.82:1`）、`colorWarning:#DFA050`（`2.26:1`）、`colorError:#D9645C`（`3.54:1`）**继续保留给桌面端的图形/边框/图表填充**；移动端「文字与图标」一律改用上表的 `-fg`。二者共用同一色相，视觉不断裂。
>
> info 的 `#3D5CD6` 与品牌 `#5F86FF` 同属 225°–228° 蓝相，是品牌蓝的加深版，不是新色相。

### 2.5 ⭐ 预警三级令牌（红 / 橙 / 黄）

**强制三重编码：底色 + 图标 + 文字**，任何一级都不得只靠颜色区分。

| 级别 | 底色 `-bg` | 描边 `-bd` | 文字/图标 `-fg` | 左侧色条 | 图标建议 | 文字标签 |
|---|---|---|---|---|---|---|
| **红色预警** | `#FDE9EE` | `#F7C9D3` | `#B8324A` | `#B8324A` | 三角警示 `alert-triangle`（实心填充） | 「红色预警」 |

| `#B8324A` on `#FFFFFF` | `5.84:1` | ✅（白卡上直接排文字也达标） |
| `#A0580D` on `#FFF3E2` | `4.92:1` | ✅ |
| `#A0580D` on `#FFFFFF` | `5.39:1` | ✅ |

## 3. 字阶（Type Scale）

字体族沿用 `global.css`：
`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', Helvetica Neue, Arial, sans-serif`

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--fs-num` | `26px / 1.15` | 600 | 数据卡大数字（`tabular-nums`） |

| `--fs-btn` | `15px / 1.45` | 500 | 按钮文字、待办标题、分段单选（介于 `--fs-lg` 16 与 `--fs-md` 14 之间） |

## 7. 动效（Subtle 级）

```css
--t-press:  80ms;   /* 按压反馈 transform: scale(.97) */
--t-base:  150ms;   /* 通用颜色/边框过渡 */
--t-enter: 200ms;   /* 页面/卡片入场 */
--t-sheet: 240ms;   /* 底部抽屉入场 */
--t-exit:  160ms;   /* 离场（必须快于入场） */
--ease-out: cubic-bezier(.22,1,.36,1);
--ease-in:  cubic-bezier(.4,0,1,1);
```

| 场景 | 规格 |
|---|---|
| 按压 | `transform: scale(.97)`，`transition: transform .08s` — **全站统一，不用 touch 事件** |
| Toast | 顶部居中，z-2000，停留 `2.6s` 后 `320ms` 淡出 |
| 页面切换 | `opacity 0→1` + `translateY(10px→0)`，`200ms` |
| 抽屉入场 | `translateY(100%→0)`，`240ms var(--ease-out)`；离场 `160ms var(--ease-in)` |
| 打卡成功 | 仅 `opacity` + `scale`，≤`200ms`，不做弹跳 |

**降级（必须落到终态）**

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;              /* 关键：只压 duration 会停在起始帧 */
    transition-duration: 0.001ms !important;
  }
}
```

## 9. 安全区

## 10. ⭐ 布局铁律：sticky，不是 fixed

> 直接引用参考稿 §2.5 的踩坑记录：滚动容器若带 `transform`（本项目页面入场动画正是 `translateY`），会成为 `position: fixed` 的包含块，导致吸附层**跟着内容一起滚走**。

```css
/* ✅ 底部吸附操作条 */
.m-actionbar {
  position: sticky; bottom: 0; z-index: 40;
  margin-top: var(--sp-3);
  padding: 10px 14px calc(10px + var(--safe-b));
  background: var(--m-surface);
  border-top: 1px solid var(--m-border);
  box-shadow: var(--m-shadow-float);
}
.m-actionbar .btn { min-height: var(--h-btn-bar); }

/* ✅ 锚在吸附栏上方的浮层：绝对定位 + bottom:100%，不是 fixed */
.m-morph { position: absolute; left: 0; right: 0; bottom: 100%; z-index: 2; }

/* ✅ 顶部锚点 Tab */
.m-tabs { position: sticky; top: 0; z-index: 5; }

/* ❌ 禁止 */
.m-actionbar { position: fixed; bottom: 0; }
```

**滚动容器唯一**：每个页面只有 `.m-scroll`（`flex:1; overflow-y:auto`）一个滚动容器，吸附/遮罩/浮层全部以它为基准。
**TabBar 的位置**：放在布局外壳（`BasicLayout`）里、作为滚动容器的**兄弟节点**（flex 列布局的最后一个成员）。若因历史结构必须放进滚动容器，则写 `position: sticky; bottom: 0; z-index: 50`，**仍然禁止 fixed**。
