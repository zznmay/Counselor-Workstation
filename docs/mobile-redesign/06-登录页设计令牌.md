## 0. 一句话结论（先看这里）

登录页不是「重新选一套设计系统」，而是既有「未来界面蓝」体系的一次**页面级增量**：**新增 `--login-*` 令牌**（非对称圆角 / 头图 / 标题 / 胶囊输入 / **品牌蓝渐变主按钮** / 协议声明行 / 静态徽标），**不新增任何色相、不改一枚品牌值**。关键取值均由**实算驱动**：① 输入填充采用 **`--m-sunken #EDF2FF` + 占位符 `--m-text-2 #5A6B8C`**（填充可见 1.12:1、占位符 4.79 ✅，两维同时优于 `--m-surface-2` 方案——见 §1.4）；② 因填充加深，聚焦边由 `#5F86FF` 上提为 `--app-primary-strong #4A6FE3`（对该填充 2.96 ❌ → 4.01 ✅）；③ 头图合规小字须避开右上晕染峰值（峰值处 3.90 ❌）。

## 1. 新增令牌总表（全部标注「新增」，附取值理由）

### 1.1 非对称大圆角（本页标志性签名 · 新增）

| Token | 值 | 理由 |
|---|---|---|
| `--login-card-r-tl` | **48px** | 左上超圆角。卡片宽 = 视口 − 2×边距（375px→343px、430px→390px、360px→332px），48px ≈ **卡片宽的 12–14%**；同时 ≈ 基准头图高（276–317px）的 **15–17%**，曲线强度刚好「一眼记住」又不喧宾夺主。低于 44px 丢失签名，高于 56px 在 360px 上几何失衡。**需求摘要建议区间 44–56px → 取中值 48px**（T9 落地）。 |

### 1.2 头图区（Hero · 新增）

> ⚠️ **防误读注记**：本节布局为**内容压底**（`justify-content: flex-end`，见下方落地代码与「落位理由」）。若见「徽标距安全区顶 24px」等**居顶表述，即为 v2 遗留、已作废**（勿据此改实现）。

| Token | 值 | 理由 |

| `--login-hero-h` | **`clamp(200px, 34dvh, 320px)`** | **占屏高 34%**。双端校验：360×640 → `34%×640=217.6`，落在 [200,320] → **218px（34.0%）**；430×932 → `34%×932=316.9` → **317px（34.0%）**。`clamp` 下限 200px 防小屏被压扁，上限 320px 防大屏头图过高挤走卡片。用 `dvh` 不用 `vh`（工具栏抖动）。 |

#### 1.4.1 ⚠️ 关于「填充式输入的可感知性」的说明

**采用 team-lead 裁决：填充可见 + 占位符 4.79 ✅。** 实算：填充 `#EDF2FF` 对白卡 `#FFFFFF` = **1.12:1**（相较 `#F7F9FF` 的 1.05:1 更可见），保住了参考图「可见的浅灰填充胶囊」这一核心特征；占位符 `--m-text-2 #5A6B8C` on `#EDF2FF` = **4.79:1 ✅**（同时满足正文级 ≥4.5）。输入框识别由「可见填充 + ≥4.79:1 占位符文字」共同承担（WCAG 1.4.11 对「有其他识别手段」的控件不强制 3:1 边界），并叠加极轻耳语边给出轮廓；聚焦边（`--app-primary-strong #4A6FE3`，4.01 ✅）/ 错误边（`#B8324A`）另给**强对比**反馈。此为已定方案，无分支。

> **登录页局部例外登记**：本页占位符使用 `--m-text-2`（而非全局约定的 `--m-placeholder`），原因见 §1.4 表。**仅登录页适用，不得扩散到其他页面**；其他页面的输入填充仍为 `--m-surface-2`，占位符仍为 `--m-placeholder #64718D`（4.65 ✅）。

### 3.4 归属判定小结

| 规则 | 归属 | 原因 |
|---|---|---|
| 填充色 / 占位符色 / 控件高 / 聚焦色与阴影 / 按钮高度字重 | **`ConfigProvider` 局部 theme** | AntD 有对应 token，作用域天然隔离 |
| 胶囊圆角（`border-radius:999`） | **token `borderRadius:999`（局部）** | 避免 CSS 到处补 |
| **渐变按钮背景 / 按压渐变** | **CSS（`.m-login`）** | AntD token 不支持渐变 |
| **输入 16px 字号** | **CSS（`.m-login`）** | AntD 无对应 token |
| 前置图标色 / 密码眼睛色 | **CSS** | 无 token |
| 复选框 18×18 | **`src/styles/mobile.css` 全站修正（非作用域覆盖）** | 修正 `.m-box` 22px 偏差，待办打卡与登录页共用 |
| 登录页勾选态颜色（品牌蓝 `#4568D8`） | **CSS（`.m-login` 作用域）** | 仅登录页改蓝，覆盖全局绿；属页面级例外 |
| Hero / 卡片非对称圆角 / 徽标 / 协议行结构 | **组件改造 + CSS** | 属新增结构 |

## 4. 不要做的事（禁区清单）

1. **不引入新色相**：只允许既有蓝族（`#5F86FF` / `#A9C2FF` / `#2F3E66` / `#4568D8` / `#3A5BC8` / `#3D5CD6`）及其深浅，禁止引入绿/紫/青等第二色相。
2. **不用纯黑**：主按钮固定品牌蓝渐变，禁 `#000`、禁深界面蓝皮肤（用户已取消）。
3. **品牌六枚令牌值一字不改**（`#5F86FF`/`#4A6FE3`/`#A9C2FF`/`#2F3E66`/`#5A6B8C`/`#E7EEFB`）。
4. **不做设备外框 3D 立体感**：那是参考图的展示 mockup 外壳，**不是产品 UI**。
5. **不用风景 / 校园照片**：头图只用品牌水彩渐变 + 「杭」徽标 + 校名（无照片、无 AI 生成图）。
6. **不新增假入口与死链**：三枚徽标**必须静态不可点**（禁 `cursor:pointer`/`:hover`/`:active`）；协议名指向本地底部抽屉，不外链。
7. **不做登录门控**：协议行**不参与校验、不阻断登录**（未勾选也照常提交），不弹门控提示、不置灰按钮。
8. **移动端阴影仅一级**：卡片只用 `--m-shadow-card`，**禁叠两级阴影**、禁 3D 重阴影、禁 hover 抬升。
9. **不用渐变文字**：标题 / 数字保持纯色（Anti-Slop）。
10. **不改后端契约**：仅 `POST /api/auth/login`、`POST /api/auth/change-password`，不虚构功能。
11. **不在同页重复提示**：「忘记密码请联系管理员」**只保留一处**（与页底既有提示去重合并，T4）。
12. **不使用 emoji 作图标**：统一 AntD 图标集，防风格分裂。
13. **不靠颜色单一表达状态**：勾选 / 错误 / 改密规则 / 徽标状态一律「颜色 + 图标 + 文字」三编码。
14. **输入字号不得低于 16px**、热区不得低于 44px、相邻可点间距不得低于 8px。
