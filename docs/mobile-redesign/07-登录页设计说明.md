## 0. 一句话结论

这是一次**页面级增量**：沿用「未来界面蓝」品牌体系，把参考图的**版式语言**（上部头图 + 下部白卡、非对称大圆角、填充式胶囊输入、全宽胶囊主按钮、三格方块）**整体转译**为真实产品 UI——**不改品牌色、不引入新色相、不新增后端能力**。效果图一次给出 **5 个状态**（默认 / 聚焦 / 错误 / 登录中 / 首次改密），全部为**纯 HTML + 内联 CSS + 内联 SVG**，无外链、无 CDN、无 `<script>`。

## 3. 主理人裁决与需求的落地说明（4 项）

### 3.1 协议勾选「不门控、默认已勾选」（**勾选态=品牌蓝，登录页局部例外**）
- 效果图中 **S1/S2/S3/S4 的协议复选框均为已勾选态**（品牌蓝实底 + 白勾）。
- **无任何门控反馈**：主按钮始终可用，不存在「未勾选不能登录」的拦截与提示态（S6 状态**不产出**）。
- 实现：`<input class="cbx" type="checkbox" checked>`，纯 CSS 勾选态 = **`--app-primary-action #4568D8` 底**（on 白 4.97 ✅）+ 白勾（**颜色 + 图标双编码**，符合 `06` §4 禁区 12）。
- **局部例外 + 理由（主理人裁决）**：**登录页**勾选承载的是「**同意声明**」语义，而非「任务完成」；用 success 绿会在本页「蓝 + 白 + 灰」单一语言上引入无关语义色，故本页改用品牌蓝 `#4568D8`。**此为登录页局部例外，不改全站**——全站待办 / 打卡仍用 success 绿（`--success-solid #25794A`）。

### 3.2 输入填充用手感更明确的 `--m-sunken #EDF2FF`（**覆盖 06 §1.4 主方案**）
- `06` §1.4 主方案原选 `--m-surface-2 #F7F9FF`（与白卡 1.05:1，**填充几乎不可辨**，会丢掉参考图「灰色胶囊」特征）。
- 主理人裁决：**改用 `--m-sunken #EDF2FF`** 作填充，**占位符同步改用 `--m-text-2 #5A6B8C`**：
  - `#5A6B8C` on `#EDF2FF` = **4.79:1 PASS**（实算，见 §5）；
  - 输入文字 `#2F3E66` on `#EDF2FF` = **9.36:1 PASS**。
- 保留 `1px solid rgba(95,134,255,.16)` 极轻耳语边。效果图中「填充可见 + 文字清晰」两项目感均已达成。
- ✅ **下游已同步**：`06` §1.4 与 §3.2 的 `loginTheme` 已更新为 `colorBgContainer:'#EDF2FF'` / `colorTextPlaceholder:'#5A6B8C'`（设计系统专家已完成登记，见 §7 协作）。

### 3.3 主按钮 = 品牌蓝渐变（**只此一种皮肤**）
- `background: linear-gradient(135deg,#4568D8 0%,#3A5BC8 100%)`；白字逐端点实算 **4.97 / 5.98 PASS**。
- **不产出**深色/纯黑变体，**不含**任何皮肤切换开关（`06` §1.5 的「备用皮肤」在本效果图中不出现）。

### 3.4 头图 = 品牌蓝水彩渐变 +「杭」徽标 + 校名（无照片 / 无 AI 图）
- 头图背景**复用 `.m-shell` 四层水彩**（逐层同值，见 `06` §1.2），挂在 `.screen` 上铺满整屏 → 卡片浮于其上，**无接缝、无生硬横切线**。
- 内容仅「杭」渐变徽标 + 「杭科院 · 辅导员工作台」+ 合规小字；**零素材依赖**、规避「虚构校园形象」风险。

## 4. 开发落地要点（供进入代码阶段）

> 归属判定与可粘贴片段详见 `06` §3；此处给「本效果图 → 生产实现」的落点清单。

### 4.1 结构：`.m-login` 作用域 + `.m-shell` 水彩背景
- 登录路由根节点由现有内联 `minHeight:'100vh'` 改为结构化 `.m-login` 容器，并挂既有 `.m-shell` 水彩背景；**所有登录页专属样式写在 `src/styles/mobile.css` 的 `@media (max-width:768px)` 内、`.m-login` 作用域下**，与既有 `.m-inp` / `.ant-*` 默认样式**零冲突**（对齐 `06` §3.3）。
- 新增结构（非样式微调）：① Hero 区（徽标 + 品牌名 + 合规小字）；② 协议勾选行；③ 底部三徽标区。三者均为 `.m-login` 内新 DOM。

### 4.2 视口高度：`100dvh` 而非 `100vh`
- 现有登录页用 `100vh`，移动端浏览器工具栏会导致抖动/裁切；改为 `100dvh`（`06` §3.1 第 1 条）。键盘弹起时配合单列布局，主按钮**可滚动到达、不被永久遮挡**。

### 4.3 安全区（顶部 + 底部）
- `<meta name="viewport" content="…, viewport-fit=cover">`（本效果图已含）。
- 顶部：状态栏/头图让出 `env(safe-area-inset-top)`；生产用 `env()`，原型用 `44px` 模拟。
- 底部：卡片下留白 `padding-bottom: calc(18px + env(safe-area-inset-bottom))`，避免被小黑条遮挡。

### 4.4 AntD `ConfigProvider` 局部主题落点（引用 `06` §3.2）
- 用 **局部 `<ConfigProvider theme={loginTheme}>`** 仅包裹登录路由，**不污染桌面端 / 全站**。
- 能由 token 表达的（填充色、占位符色、控件高、聚焦色/阴影、按钮高字重、`borderRadius:999`、复选框 18）走 `loginTheme`；
- token 表达不了的（**渐变按钮背景**、**输入 16px 字号兜底**、图标色、密码眼睛色、`.m-box` 18×18 覆盖）走 `.m-login` 作用域 CSS（`06` §3.4）。
- ⚠️ `loginTheme.components.Input` 的 `colorBgContainer / activeBg / hoverBg` 改为 `'#EDF2FF'`、`colorTextPlaceholder` 改为 `'#5A6B8C'`（随 §3.2 裁决）。
- ⚠️ **聚焦态（v3 更新）**：`Input.activeBorderColor` 由 `'#5F86FF'` 改为 **`'#4A6FE3'`**；`Input.activeShadow` 保持 **`'0 0 0 3px rgba(95,134,255,.34)'`**（即既有 `--m-ring`，标准「深边 + 柔环」）；作用域 CSS `.m-login .ant-input-affix-wrapper-focused{border-color:var(--app-primary-strong); box-shadow:0 0 0 3px var(--m-ring)}`。理由见 §5.3.1。

### 4.5 红线与禁用项
- **禁用** `position:fixed`（除全屏浮层遮罩）；移动端卡片阴影**仅一级**；**无横向滚动**（`overflow-x:hidden`）。
- **不改后端契约**：仅 `POST /api/auth/login`、`POST /api/auth/change-password`，无社交登录、无自助找回。

#### 5.3.1 聚焦边选型记录（v3 更新：`#5F86FF` → `#4A6FE3`）
